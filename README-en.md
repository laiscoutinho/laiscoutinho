## ✨ About Me

**Frontend Developer** focused on building accessible, scalable, and interactive interfaces driven by user experience.

I work with **React, TypeScript, and Angular**, structuring projects that prioritize:

- Component-based architecture
- Clear separation of concerns
- Standardization and maintainability
- Performance and user experience
- Developer Experience (DX)
